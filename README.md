## ⚡ Beyond a Standard Portfolio
This is not a traditional static resume. It is a highly interactive web experience pushing the boundaries of front-end architecture, rendering pipelines, and user psychology. Built with heavy use of `framer-motion` for buttery smooth spring physics, page transitions, and micro-interactions.

## 🚀 Key Features

* **Cinematic UI/UX:** Glassmorphism, dynamic glowing neon gradients, and layered parallax elements create a deep 3D feel on a 2D canvas.
* **Fully Functional CLI Mode:** A simulated terminal built directly into the React DOM. Users can type real commands to interact with the underlying state of the portfolio.
* **X-Ray / Wireframe Mode:** A toggleable developer mode that strips away the styling, revealing the bare structural wireframes and bounding boxes of the site's architecture.
* **Fluid Physics Sandbox:** Interactive gravity simulations where DOM elements become physical objects you can drag and throw.
* **Optimized Performance:** Leverages Vite for lightning-fast Hot Module Replacement and highly optimized production bundling.

## 🎮 Hidden Easter Eggs (Try these in the CLI!)

Open the Terminal (via the `>_ CLI MODE` button or by triggering the Konami Code: `↑ ↑ ↓ ↓ ← → ← → B A`) and run these commands:

| Command | Action |
| :--- | :--- |
| `help` | Lists all available system commands. |
| `hack` | Initiates a simulated global system compromise overlay that violently takes over the DOM. |
| `selfdestruct` | **DANGER:** Forces a fatal React Kernel Panic, intentionally crashing the app to a custom Error Boundary recovery screen. |
| `play` | Launches **Neon Snake**, a fully playable retro arcade game built inside the CLI. |
| `sweep` | Launches **Bug Sweeper**, a developer-themed Minesweeper clone. |
| `gravity` | Turns on a 2D physics engine, letting UI elements fall and bounce. |
| `matrix` | Initiates the classic digital rain effect across the terminal background. |

## 💻 Running Locally

To run this digital monument on your own machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Aethron-fr/My_PortFolio.git
   ```

2. **Navigate to the directory**
   ```bash
   cd My_PortFolio
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the Vite development server**
   ```bash
   npm run dev
   ```

5. **Initialize Sequence**
   Open your browser and visit `http://localhost:5173`
